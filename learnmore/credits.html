ColorCramer adapts the original ColorBrewer-style workflow for modern scientific palettes by using Fabio Crameri colour maps and a regenerated palette dataset for the browser.

This project keeps the interactive map-based evaluation interface while replacing the palette source with perceptually designed ramps suitable for scientific and cartographic use.

The site is provided as-is. Palette design remains the work of Fabio Crameri, while this web implementation and repository maintenance are credited in the project source.

ColorCramer also builds on ideas popularized by the original ColorBrewer interface and later browser implementations of map-focused palette diagnostics.
